# Project Summary

In this project, USDA agricultural production datasets were analyzed using SQL and SQLite within a Python environment. The analysis covered multiple commodities, including milk, cheese, coffee, honey, and yogurt production across U.S. states. You can check the code on [here].(https://github.com/rishi-analytics/sql-for-data-science-usda-production-analysis/blob/main/notebook/USDA_production_datasets_SQL_final_project.ipynb)

## Workflow

- Built and implemented a SQLite database in Google Colab
- Imported and structured multiple CSV datasets
- Cleaned and standardized numeric production values
- Applied SQL querying techniques to solve analytical business questions
- Generated operational insights through structured data analysis

## SQL Techniques Applied

- Aggregations (`SUM`, `AVG`, `MAX`)
- Filtering with `WHERE` and `HAVING`
- `GROUP BY` analysis
- `INNER JOIN` and `LEFT JOIN`
- Subqueries and Common Table Expressions (CTEs)
- NULL handling with `COALESCE`
- Data cleaning and type conversion

## Key Insights

- Milk production dominated overall agricultural output
- Dairy commodities showed regional production specialization
- Cross-commodity analysis identified overlapping production patterns across states

## Tools Used

- SQL
- SQLite
- Python (`sqlite3`)
- Google Colab

## Outcome

This project demonstrates practical SQL-based data analysis, relational database querying, data cleaning, and analytical problem solving using real-world structured datasets.
